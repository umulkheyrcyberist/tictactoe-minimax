How the computer decides

Minimax is a classic decision method for two-player games. The computer plays the whole game in its head, then chooses the move that leads to the best result.

  1. Try every moveIt imagines each empty square, then every reply, until the game ends.
  2. Score each ending+1 if the computer wins, −1 if you win, and 0 for a draw.
  3. Choose the best branchIt picks the move with the highest score, assuming you will always pick the lowest.
